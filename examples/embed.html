Smart Intake embed test: three mounts on one page

1. Declarative — no JavaScript of your own

The page just has a <div data-intake-widget>. The script finds it on load and mounts into a shadow root. Categories come from a comma-separated attribute.

2. Imperative — dark theme, sales categories, compact

Mounted via SmartIntake.mount() with options passed as an object.

3. Shadow DOM off — inherits the host's terrible CSS

Same widget with shadow: false. Scoped class names still stop the widget leaking out, but the host's button, textarea and list rules now leak in. This is the failure mode shadow DOM exists to prevent.
