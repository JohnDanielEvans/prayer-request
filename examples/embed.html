Embed test: three mounts on one page

1. Declarative — no JavaScript of your own

The page just has a <div data-prayer-widget>. The script finds it on load and mounts into a shadow root.

2. Imperative — dark theme, custom categories, compact

Mounted via PrayerWidget.mount() with options passed as an object.

3. Shadow DOM off — inherits the host's terrible CSS

Same widget with shadow: false. Scoped class names still prevent the widget from leaking out, but the host's button and textarea rules now leak in. This is the failure mode shadow DOM exists to prevent.
